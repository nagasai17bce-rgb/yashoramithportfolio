# Yasho Ramith - Portfolio Website

Minimal, modern, dark terminal portfolio website built for **Yasho Ramith** (Senior Member of Technical Staff - AI Platform Engineering at Salesforce).

## 🚀 Features
- **Dark Minimal Developer Theme**: Inspired by developer terminals and minimalist engineering sites.
- **Fast & Lightweight**: Built with pure HTML, Tailwind CSS, and lightweight Vanilla JS.
- **Responsive & Mobile Ready**: Fully optimized layout across mobile, tablet, and desktop viewports.
- **Automated Deployment**: GitHub Actions workflow included for instant automatic publishing to GitHub Pages.
